Connect Max's AI

Max needs a Cloudflare Worker URL to send your question to the AI model securely. The Worker keeps your Gemini API key off this website.

Enter only the Worker base URL. Do not enter your Gemini API key here.

What must be set up in Cloudflare?
  1. A deployed Worker containing the Max backend code.
  2. A Worker secret named GEMINI_API_KEY.
  3. A plain-text variable named ALLOWED_ORIGIN set to https://navigator-isle.github.io.
  4. Then save the Worker URL here and test it.
