    What must be set up in Cloudflare?
    1. A deployed Worker containing the Max backend code.
    2. A Worker secret named GEMINI_API_KEY.
    3. A plain-text variable named ALLOWED_ORIGIN set to https://navigator-isle.github.io.
    4. For memory: a D1 binding named MAX_MEMORY and a secret named MAX_PASSCODE.
    5. Then save the Worker URL and passcode here and test it.
