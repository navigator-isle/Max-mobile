**TDC Code — Code of Safe Practice for Ships Carrying Timber Deck Cargoes (2011 TDC Code)**

**What is the TDC Code**
- IMO guidance on stowing, securing and carrying timber (logs, sawn wood, cants, pulpwood) on deck
- Recommendatory (Assembly resolution), but used with SOLAS VI/5 (Cargo Securing Manual) and the Load Line Convention (timber freeboard)
- Covers stability with timber deck cargo, lashing systems, crew safety

**History**
- 1972 first TDC Code · 1991 Code (A.715(17))
- 2011 TDC Code adopted 30 Nov 2011 (A.1048(27)) · replaced the 1991 Code
- 2011 Code changed to performance-based securing (calculations like CSS Annex 13) and added uprights for logs

**Applies to**
- All ships ≥24 m carrying timber deck cargo
- Ships assigned timber load lines (Load Lines Convention reg 41–45, 1966/1988) — reduced freeboard only if timber deck cargo is stowed and secured properly

---

**Part A — Operational requirements**
- Ch 1 General: purpose, application, definitions (timber, timber deck cargo, timber load line, uprights, lashing)
- Ch 2 Stability:
  - Loading condition in the stability booklet · allow for water absorption (+10% weight of deck timber) and ice accretion
  - Metacentric height (GM) ≥0.10 m at all times (incl. end of voyage) · avoid excessive GM (violent rolling)
  - Loss of cargo or shift from list — monitor list during loading
- Ch 3 Before loading: check lashing equipment certified, uprights and sockets, deck fittings; plan per Cargo Securing Manual
- Ch 4 Loading and stowage:
  - Stow compactly, no gaps; deck cargo height within visibility limits (SOLAS V/22) and stability limits
  - Height on deck generally ≤ the limits in the manual · access protection: guardrails/lifelines (≥1 m high) across the cargo, safe walkways
- Ch 5 Securing:
  - Logs: uprights (stanchions) + hog/loop lashings + wiggle wire as designed; uniform tension
  - Sawn wood (packaged): independent lashings over each row, spacing per manual (generally ≤3 m)
  - Lashing tension checked and tightened regularly during the voyage
- Ch 6 Personnel safety: walkways, lifelines, lighting, PPE, no walking on top in bad weather
- Ch 7 Voyage planning and voyage: avoid heavy weather if possible; check and re-tension lashings · procedures if cargo shifts or list develops (jettisoning only as last resort, with master's decision)

**Part B — Design principles (securing arrangements)**
- Ch 1 General · Ch 2 Design of timber deck cargo securing arrangements:
  - Forces from ship motions and green seas · friction coefficients (wood on wood, wood on steel)
  - Securing system strength: MSL of lashings and uprights · uprights strong enough for transverse forces
- Ch 3 Physical properties of timber cargoes (densities, friction, water absorption)
- Annexes: calculation examples, lashing types (loop, hog, wiggle wire, chains), maintenance

**Load Line link (timber freeboard)**
- Timber load lines (LT, LS, LW, LWNA, LTF, LF) marked aft of the load line disc
- Can be used only when timber deck cargo is stowed solid, height ≥ standard height of superstructure (generally), and secured per the rules

**Key Point**
- GM must stay positive with margin at arrival (water absorption +10%, ice, consumption of fuel and water)
- Lifelines/guardrails and safe walkways over the cargo before sailing
- Re-tension lashings daily and after heavy weather; record it
- Timber load lines only valid with properly stowed and secured deck cargo
