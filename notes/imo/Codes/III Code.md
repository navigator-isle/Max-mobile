**III Code — IMO Instruments Implementation Code**

**What is the III Code**
- Standard for how States implement and enforce IMO conventions — as flag State, coastal State and port State
- Basis of the mandatory IMO Member State Audit Scheme (IMSAS): every Member State is audited on its performance
- Not for ships or companies directly — for governments (maritime administrations like MARINA, USCG, AMSA)

**History**
- Voluntary Member State Audit Scheme 2005 (A.946(23)) · Code for the implementation of mandatory IMO instruments (A.996(25), 2007)
- III Code adopted 4 Dec 2013 by Assembly resolution A.1070(28) · replaced the 2011 Code for the Implementation of Mandatory IMO Instruments (A.1054(27))
- Made mandatory through amendments to SOLAS, MARPOL, STCW, Load Lines, Tonnage, COLREG (and their protocols) — in force 1 Jan 2016
- IMSAS: framework and procedures A.1067(28) · audits started 2016 (about 7-year cycle)

**Applies to**
- All Contracting Governments to the mandatory instruments: SOLAS 74 and 88 Protocol · MARPOL · STCW · LL 66 and 88 Protocol · Tonnage 69 · COLREG 72

---

**Part 1 — Common areas**
- Objective · strategy (policy, legislation, resources to implement and enforce)
- General obligations: law to give full effect to the instruments · communication of information to IMO (mandatory reporting)
- Initial actions: when a State becomes Party — legislation, administration, procedures
- Records · improvement (continuous review, corrective actions from audits)

**Part 2 — Flag States**
- Implementation: laws, regulations, guidance · delegation of authority to Recognized Organizations (RO Code) with oversight
- Enforcement: inspections, surveys, investigations, penalties strong enough to deter violations
- Flag surveyors: qualified, trained, independent
- Investigations of marine casualties (Casualty Investigation Code) and reporting to IMO (GISIS)
- Evaluation and review of flag performance (detention rates, casualties)

**Part 3 — Coastal States**
- Implementation of coastal duties: hydrographic services, SAR, navigational warnings, ships' routeing, VTS, pollution response
- Enforcement in territorial sea and EEZ within UNCLOS limits

**Part 4 — Port States**
- Port State control in line with IMO procedures (resolution A.1185(33) Procedures for PSC) · regional MoUs (Tokyo, Paris, etc.)
- Reception facilities for ship wastes (MARPOL) · reporting of deficiencies and detentions to flag and IMO
- No more favourable treatment for ships of non-Parties

**Annex — mandatory obligations by instrument** (list of what each instrument requires of States)

**Why it matters on board**
- Your flag's performance (IMSAS results, PSC record) affects how ships under that flag are targeted by PSC
- Flags on Paris/Tokyo MoU white/grey/black lists use the III Code framework for improvement

**Key Point**
- III Code = the "ISM Code for governments": policy, procedures, records, audits, continuous improvement
- Philippines: MARINA is audited as flag/port/coastal State under IMSAS (with PCG for coastal/port duties)
- Results of IMO audits are confidential summaries shared with Member States (GISIS)
