**HSC Code (International Code of Safety for High-Speed Craft)**

**Status**
- 2000 Code checked against the IMO resolution text (MSC.97(73)): dates, application, chapters, definitions
- Corrected from the first draft: chapters 13 to 15 and the Category A definition
- 1994 Code application date still to be verified

**What is HSC**
- Safety standards for high-speed craft such as fast ferries, hovercraft, hydrofoils, catamarans
- Mandatory under SOLAS Chapter X

**History**
- HSC Code 1994: MSC.36(63), for craft built on or after 1 Jan 1996 (to verify)
- HSC Code 2000: MSC.97(73), adopted 5 Dec 2000
- 2000 Code in force 1 Jul 2002
- Amendments adopted MSC 111 (May 2026): VDES allowed as optional alternative to AIS (same as SOLAS V) — in force 1 Jan 2028

**Applies to**
- 2000 Code: high-speed craft on international voyages with keel laid, or at a similar stage of construction, on or after 1 Jul 2002
- High-speed craft: maximum speed in m/s equal to or above 3.7 × ∇^0.1667 (∇ = displacement volume at the design waterline in m³)
- Craft fully supported above water by ground-effect forces in non-displacement mode are excluded

- 18 Operational requirements
- 19 Inspection and maintenance requirements

**Craft categories**
- Category A passenger craft: route where flag and port States have shown a high probability that all can be rescued safely; rescue within the shortest of the hypothermia time, a time suited to the route, or 4 hours; no more than 450 passengers
- Category B passenger craft: not Category A; machinery and safety systems arranged so that if the essential systems in one compartment are disabled the craft can still navigate safely
- Cargo craft: separate rules

**Key Point**
- Certificates: High-Speed Craft Safety Certificate and Permit to Operate
- Crew need a type rating and recurrent training on the craft
